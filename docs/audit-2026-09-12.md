# Auditoría inicial — 2026-09-12

La auditoría se ejecutó por SSH y fue exclusivamente de lectura.

## Sistema

- Debian 13.6 (trixie), kernel 6.12.100+deb13-amd64, x86-64.
- Plataforma x86-64 de consumo con procesador de cuatro núcleos.
- 12 GB de memoria RAM.

## Almacenamiento

- Un disco SATA mecánico de aproximadamente 1 TB.
- Raíz ext4 en `/dev/sda2`, con cerca de 1% utilizado.
- No se detectaron MD RAID, LVM, ZFS o Btrfs.
- `smartctl` y `mdadm` no están instalados.

## Servicios y red

- Apache 2.4.68 en `*:80`, con el único sitio `000-default.conf`.
- Docker y Compose activos, con cargas preexistentes que debían preservarse.
- OpenSSH 10.0 en el puerto 22.
- Una interfaz LAN y una red privada superpuesta activas; sus nombres y direcciones se omiten deliberadamente.
- Puertos 443, 8085 y 9105 libres durante la auditoría.
- No se detectó libvirt/QEMU ni máquinas virtuales.

## Sensores

- CPU Package alrededor de 36 °C; núcleos entre 35 y 37 °C.
- Sensores ACPI alrededor de 28–30 °C.
- Ventilador principal alrededor de 1048 RPM.
- El sensor de `-128 °C`, conectores de ventilador sin giro y la alarma de intrusión requieren filtrado contextual.

## Riesgos relevantes

- No existe firewall de host activo y la política INPUT es permisiva.
- Apache y SSH escuchan en todas las interfaces.
- El sitio Apache predeterminado debe preservarse durante el despliegue.
- SMART no estará disponible hasta instalar `smartmontools`.
- Las etiquetas de varios sensores de placa no son suficientemente fiables para inventar nombres funcionales.
