# SHC Monitor v0.5.1

La tabla de puertos incluye el nombre del servicio. Se identifica mediante el proceso que escucha y los puertos publicados de Docker. Como alternativa se usa el nombre estándar del puerto, indicado en el tooltip; los desconocidos se muestran como «No identificado».

Incluye identificación de SSH, Apache, VNC/KVM, SHC, ZeroTier, containerd, Cockpit y DNS/DHCP. El inventario se cachea 15 segundos. La regla `shc-ports.sudoers` permite únicamente consultar los sockets mediante `ss -H -lntup` para resolver procesos de otras cuentas.
