# SHC Monitor v0.10.2

- Indicador de conexión del anfitrión en la barra superior de todas las pestañas, junto al reloj.
- Identifica la interfaz elegida por la tabla de rutas para la salida IPv4; admite ruta predeterminada IPv6 como alternativa. No usa la conexión del navegador ni elige arbitrariamente una interfaz Docker/KVM.
- Ethernet se muestra como ETH; Wi-Fi muestra tres arcos que cambian según la señal. Otras interfaces y la ausencia de ruta tienen estados diferenciados.
- Ayuda al pasar el mouse con interfaz, señal dBm y porcentaje estimado. El porcentaje es una aproximación basada en dBm, no una medición de velocidad.
- Reutiliza las lecturas existentes cada dos segundos; no agrega sondeos de red, permisos privilegiados, dependencias ni nuevas consultas del navegador.
- Señal o métricas no disponibles se muestran sin inventar intensidad ni conservar una lectura anterior como actual.
