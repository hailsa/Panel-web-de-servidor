# SHC Monitor v0.8.1

El asistente incluye un explorador de carpetas del servidor para seleccionar la ISO de instalación o la de controladores. Muestra sólo carpetas y archivos ISO, admite rutas de carpetas, navegación al padre y filtro por nombre.

Las ubicaciones adicionales se configuran fuera de Git en `/etc/shc-monitor/iso-library.json`, propiedad de root y sin escritura para otros usuarios. Ver `config/iso-library.example.json`. Las rutas se validan tanto al explorar como al previsualizar y crear; no se permite salir de las bibliotecas autorizadas.

Para medios dentro de directorios personales privados, el helper prepara un enlace en el área de medios de libvirt. Requiere que la ISO ya tenga lectura para QEMU y esté en el mismo sistema de archivos. No modifica los permisos de la carpeta personal ni duplica el archivo. Si el medio está en otro sistema de archivos, se solicita copiarlo previamente a la biblioteca de libvirt.

Las ISO se agregan al XML como CD-ROM de sólo lectura, sin interpolar sus nombres como opciones de virt-install.

Cuando el aislamiento de systemd separa los montajes del collector, la preparación se delega a `shc-iso-prepare@.service`. Recibe sólo el UUID de una solicitud propiedad de root y revalida el origen antes de enlazar el medio. El collector conserva `ProtectSystem=strict`.
