# SHC Monitor v0.8.2

- Las vistas de VM y Docker consultan cambios cada tres segundos sin recargar el documento ni desconectar la consola VNC.
- Al ejecutar una acción se descartan consultas anteriores y se realiza una nueva al completarse la solicitud. El estado final se confirma mediante el inventario del servidor.
- Notificaciones dentro de la página, bajo la campana, con cierre automático a los cinco segundos.
- Las acciones y cambios confirmados se conservan en el historial local de la campana (hasta 50 entradas), incluso después de ocultarse el aviso. Abrir el historial marca la actividad como leída.
- Los eventos de actividad no se resuelven como si fueran alertas de hardware; las consultas repetidas no duplican los avisos de un mismo error.
- Las páginas ocultas y los diálogos abiertos pausan el refresco. La vista se actualiza al volver a la pestaña.
