# SHC Monitor v0.9.0

- IPv4/IPv6 en visión general e interfaces, con fuente de detección y mensajes claros cuando no hay datos.
- Consulta `domifaddr --full` para conservar todas las direcciones de una misma placa; evita mostrar datos antiguos de VM apagadas.
- Editor modal y agregado de interfaces: NAT/red libvirt, puente existente o macvtap bridge para la LAN, modelo, MAC, cable virtual, MTU y colas VirtIO.
- Las redes se descubren en el host; se validan origen, modelo, MAC, duplicados y límites de recursos.
- Cambios sólo con VM apagada, respaldo privado del XML y validación de libvirt. No se cambia la red del host ni se apagan VM automáticamente.
- El refresco respeta el editor abierto; las actualizaciones de configuración quedan en las notificaciones existentes.
- Documentación de DHCP/IP fija, controladores, firewall y limitación de comunicación con el host en macvtap.
