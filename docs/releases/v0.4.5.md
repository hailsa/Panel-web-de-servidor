# SHC Monitor v0.4.5

- Se reemplaza la autenticación HTTP Basic por una página de acceso con cuentas locales en SQLite y sesiones revocables.
- Se conserva el hash bcrypt del usuario `hailsa` existente al migrar el servidor; la contraseña no se copia al repositorio.
- Se incorpora una consola interactiva desplegable que abre una shell como el usuario del collector en el host.
- Se corrige la elevación limitada de privilegios requerida para apagar y reiniciar el servidor.
- Se agrega una comprobación previa de permisos antes de aceptar acciones de energía.

La cuenta de prueba `admin` se crea durante el despliegue, fuera de Git. La consola y las acciones de energía quedan disponibles solo tras iniciar sesión por HTTPS desde las redes autorizadas.
