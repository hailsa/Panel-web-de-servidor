# SHC Monitor v0.6.1

El inventario Docker muestra las imágenes etiquetadas y todas las vinculadas a contenedores, incluso detenidos. Las imágenes sin etiqueta se ocultan por defecto y pueden mostrarse con un selector. Se identifican las imágenes en uso y se priorizan al ordenar.

La limpieza de imágenes es una operación manual de mantenimiento del host. Debe excluir imágenes referenciadas por contenedores y respaldos etiquetados; no se realiza eliminación automática desde el dashboard.
