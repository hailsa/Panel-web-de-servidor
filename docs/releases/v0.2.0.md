# SHC Monitor v0.2.0

## Cambios

- Navegación real entre Dashboard, Usuarios y Estado del Servidor.
- Inventario de cuentas locales con UID, grupos, rol, shell, home, último acceso y estado.
- Filtros para distinguir personas y cuentas de sistema.
- Vista detallada de temperaturas, voltajes disponibles, hardware, discos físicos, RAID, servicios, Docker y virtualización.
- Actualización de métricas dinámicas cada dos segundos con caché para inspecciones más costosas.
- Valores no medibles identificados explícitamente como `No disponible`; no se estiman consumo, SMART ni salud de discos.

## Seguridad

Las vistas son exclusivamente de lectura. Las credenciales, el token interno y los certificados siguen fuera del repositorio.
