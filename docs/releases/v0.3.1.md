# SHC Monitor v0.3.1

- Detección real de máquinas KVM mediante libvirt (`qemu:///system`).
- Consultas exclusivamente de lectura, con caché de 15 segundos.
- Nombre y estado de cada VM en Dashboard y Estado del Servidor.
- Los errores de acceso se distinguen de un inventario vacío.

Requiere `virsh` en el host y acceso del collector al socket de lectura de libvirt. No requiere montar libvirt en Docker ni otorgar permisos de administración de máquinas.
