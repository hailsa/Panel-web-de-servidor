# SHC Monitor v0.10.0

- Nueva pestaña Actualizaciones para el anfitrión Debian: paquetes, versiones, repositorios, retenciones, descripción, changelog y CVE relacionadas.
- Clasificación de seguridad por origen Debian Security y por correcciones verificadas del Security Tracker. Urgencia publicada sin inventar puntuaciones CVSS.
- Consulta de índices y avisos cada seis horas, además de búsqueda manual. La búsqueda sólo actualiza metadatos.
- Avisos de seguridad, búsqueda fallida y reinicio pendiente en la campana del panel.
- Botones para todas las actualizaciones o sólo seguridad: primero resuelven dependencias y simulan; la instalación requiere un plan vigente y confirmación de posibles interrupciones y respaldo de datos.
- Planes de diez minutos, versiones explícitas, revalidación en el worker y simulación independiente de APT. Rechaza eliminaciones, retrocesos, paquetes retenidos/no confiables y cambios de distribución.
- Tareas systemd persistentes fuera del proceso del dashboard/collector, con historial y registro. No mata DPKG por tiempo de espera ni reinicia automáticamente el host.
- Respaldo privado de lista de paquetes y configuraciones seleccionadas. No sustituye copias de datos, discos de VM o volúmenes.
- La base CVE se procesa por registros, conservando sólo información relevante para los paquetes instalados. Si falla esa fuente, se informa y sigue disponible la clasificación de los repositorios.
