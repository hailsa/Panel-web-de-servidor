# SHC Monitor v0.3.0

## Cambios

- Gráfico de CPU, RAM y almacenamiento con historial local de hasta 24 horas.
- Sparklines en las cinco métricas principales.
- Tráfico de red calculado en bytes por segundo.
- Tabla de los cinco procesos con mayor actividad, con PID, CPU y RAM reales.
- Dashboard reorganizado siguiendo la jerarquía del UX de referencia.
- Sistema de iconos SVG propio, liviano y servido localmente.
- Se mantiene el diseño sin ilustración decorativa del servidor.

## Rendimiento y privacidad

El historial del gráfico se conserva únicamente en el navegador y se limita a 24 horas. No se incorpora telemetría externa, CDN ni almacenamiento de métricas fuera del servidor.
