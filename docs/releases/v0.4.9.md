# SHC Monitor v0.4.9

- La shell web evita el `fastfetch` de inicio, que esperaba respuestas de terminal y detenía el prompt y los comandos.
- El collector lee la terminal de forma no bloqueante y libera el lector y el proceso al cerrar cada sesión.
- La consola muestra un error y permite reabrirse si el servidor no entrega salida en diez segundos.
- Prueba regresiva de conexiones repetidas al collector y de tiempo de espera en el navegador.
