# SHC Monitor v0.4.0

## Novedades

- Controles protegidos para reiniciar y apagar el servidor desde la barra superior.
- Centro de notificaciones para CPU, RAM, almacenamiento, temperaturas, Internet, Docker, máquinas virtuales y salud SMART.
- Historial local de incidencias, resolución automática y contador de alertas activas.
- Barra lateral contraíble en escritorio y menú móvil con cierre explícito, fondo táctil y tecla Escape.
- Uptime y estado del servidor corregidos en la vista Usuarios.
- Comprobación de conectividad externa incorporada al collector.

## Seguridad

Las acciones de energía exigen autenticación del proxy, una petición POST del mismo origen, un encabezado de confirmación y un diálogo explícito en la interfaz. El collector sólo puede elevar privilegios para `systemctl reboot` y `systemctl poweroff` mediante el grupo dedicado `shc-power`.
