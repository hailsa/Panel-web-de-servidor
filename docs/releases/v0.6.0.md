# SHC Monitor v0.6.0

- El menú «Más» de las VM usa un popover en la capa superior del navegador: no se recorta dentro de la tabla. El refresco se suspende mientras el menú o una confirmación permanecen abiertos.
- Nueva pestaña Docker: contenedores detectados automáticamente, búsqueda, filtros, consumo de CPU/RAM, imágenes, redes y volúmenes.
- Ficha por contenedor con salud, puertos publicados, redes, procesos, montajes, límites y política de reinicio.
- Iniciar, detener, reiniciar, pausar, reanudar y forzar detención con confirmaciones. La detención forzada exige escribir el nombre del contenedor.
- Consulta manual de hasta 200 líneas de logs recientes, sin refresco automático ni persistencia de logs en el navegador.
- Las variables de entorno se muestran sólo por nombre. El socket Docker sigue exclusivamente en el host.

Las acciones sobre el propio contenedor del panel se bloquean. Esta versión no elimina contenedores, imágenes, volúmenes o redes, y no recrea proyectos Compose. Cambiar la política de reinicio no modifica el archivo Compose de origen.
