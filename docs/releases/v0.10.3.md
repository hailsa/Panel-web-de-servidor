# SHC Monitor v0.10.3

- El dashboard solicita métricas cada dos segundos sin superponer solicitudes.
- Archivos permite listar, crear carpetas y archivos vacíos, mover, renombrar y eliminar archivos o carpetas vacías debajo de `/srv/shc-files`. No sigue enlaces ni sobrescribe destinos. Crear el directorio con el usuario del collector e instalar `systemd/shc-files.conf` como drop-in.
- Las sesiones del panel caducan tras diez minutos sin interacción. El sondeo de fondo no renueva la sesión y las consolas se cierran cuando vence. El primer despliegue requiere iniciar sesión nuevamente.
- Usuarios muestra las sesiones que registra logind, incluidas SSH, y la última entrada finalizada de cada cuenta cuando está registrada. La dirección es la que observa el servidor. La ubicación física, el dispositivo cliente y su IP pública detrás de una red privada no se infieren.
- Estado del servidor muestra módulos RAM, inventario PCI, puertos en escucha con servicio, y salud SMART con horas, ciclos y alertas comunicados por el disco. Inicializa la lectura al arrancar el collector y refresca la caché periódicamente. Los watts se miden en el paquete del procesador con Intel RAPL. La lectura no representa el consumo total en el enchufe.
- Las VMs muestran direcciones conocidas junto al nombre. El detalle consulta CPU y memoria cada dos segundos y diferencia RAM residente en el host de RAM usada dentro del invitado. La memoria del invitado requiere estadísticas del dispositivo balloon y controladores. El inventario TCP/UDP se obtiene del invitado con QEMU Guest Agent y permisos para las consultas fijas, sin escanear la red.
- Instalación en Debian: instalar `scripts/shc-host-telemetry.py` como `/usr/local/libexec/shc-host-telemetry` y `scripts/shc_vm_ports.py` junto al helper de libvirt. Validar `systemd/shc-host-telemetry.sudoers` con `visudo` antes de instalarlo. Los permisos son para el grupo existente `shc-power`.
- Restringir los orígenes de SSH mediante el firewall del anfitrión y los del panel mediante `Require ip` en Apache. Mantener las direcciones reales y las reglas locales del anfitrión fuera del repositorio.
- El despliegue configura el muestreo de memoria de libvirt cada dos segundos para los dispositivos VirtIO balloon compatibles. El agente y el controlador de memoria son componentes independientes.
- En el anfitrión, el despliegue limita SSH y el panel a orígenes expresamente autorizados y bloquea TCP/UDP 2222. Se verificaron las rutas LAN y ZeroTier. El ajuste local del ventilador conserva la regulación automática del firmware y solo se aplica si coinciden el controlador y los parámetros verificados.
