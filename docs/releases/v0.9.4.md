# SHC Monitor v0.9.4

- CPU y RAM del host en la barra superior, con porcentaje y barra compacta, visibles en todas las pestañas.
- RAM usada/total disponible al pasar el mouse. Los valores representan el servidor completo, no sólo la VM o el contenedor seleccionado.
- Actualización cada dos segundos. El dashboard reutiliza su consulta existente; las demás páginas consultan el snapshot sin solapar peticiones y pausan al quedar ocultas.
- Los datos ausentes se muestran con un guion, evitando presentar ceros o valores anteriores como actuales.
- Distribución adaptable: los indicadores pasan a una segunda fila en pantallas pequeñas.
