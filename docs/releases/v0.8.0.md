# SHC Monitor v0.8.0

Botón «Crear máquina virtual» y asistente de configuración desde la pestaña KVM.

- Nombre, perfil Linux/Windows/genérico, CPU, RAM, pool y disco qcow2 nuevo.
- ISO de instalación y controladores existentes en la biblioteca del host.
- Red libvirt activa o VM sin red, firmware BIOS/UEFI, TPM 2.0 y Secure Boot opcionales.
- Canal Guest Agent, autoinicio y encendido al finalizar; apagada por defecto.
- Vista previa validada con virt-install y resumen antes de confirmar.

La creación requiere virt-install, libvirt y un pool de directorios seguro bajo `/var/lib/libvirt/images`. La biblioteca ISO se limita a ese árbol y `/var/lib/libvirt/boot`. No admite rutas arbitrarias, discos existentes, nombres duplicados ni opciones libres de línea de comandos.

El helper usa bloqueo de creación, identificadores UUID e idempotencia por solicitud. Conserva el XML de cada nueva VM en `/var/backups/shc-monitor/vm-created`. Si falla la definición después de crear un volumen, el disco se conserva y se informa para revisión en lugar de borrarlo automáticamente.

Las ISO no se descargan ni suben desde este asistente. Crear la VM no instala el sistema operativo: la instalación continúa desde VNC. UEFI, Secure Boot y TPM dependen de los paquetes y capacidades disponibles en el host.

El módulo `scripts/shc_vm_create.py` se instala junto al helper como root. El drop-in `systemd/shc-vm-create.conf` permite escribir únicamente en el directorio de control de creación y en el de XML de nuevas VM; `systemd/shc-vm-create.tmpfiles` prepara esos directorios como root. Se mantiene `ProtectSystem=strict`.
