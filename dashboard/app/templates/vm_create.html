Nombre y sistema

Linux usa almacenamiento y red VirtIO. La instalación se realiza después desde la consola VNC.

CPU y memoria

La RAM se reserva al encender la VM. El asistente mantiene al menos 1 GiB para el host.

Almacenamiento nuevo

Se crea un disco qcow2 nuevo, de crecimiento dinámico. No se seleccionan ni sobrescriben discos existentes.

Instalación del sistema

Se muestran las ISO existentes bajo /var/lib/libvirt/images y /var/lib/libvirt/boot. Se montan como CD de sólo lectura.
