Alcance y continuidad del servidor

Esta pestaña administra el servidor anfitrión. No actualiza las aplicaciones de tus contenedores ni los sistemas operativos de las VM. Una actualización de Docker, Apache, libvirt, SSH o bibliotecas compartidas puede reiniciar servicios o interrumpir conexiones. Un kernel nuevo necesita reiniciar el host para entrar en uso; ese reinicio queda a tu cargo.

Antes de instalar, conservá una copia de los datos importantes y de las VM. SHC guarda la lista de paquetes y configuraciones seleccionadas, pero ese respaldo no incluye los datos, volúmenes ni discos virtuales. El modo seguridad incluye las dependencias necesarias y las muestra en el plan. No se permiten eliminaciones, versiones anteriores ni cambios de distribución.

La urgencia publicada por Debian no es una puntuación CVSS. Si no hay información verificable, se muestra «No informada». Debian Security Tracker
